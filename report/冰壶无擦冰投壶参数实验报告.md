# 冰壶无擦冰投壶参数实验报告

> 实验日期：2026-08-28
>
> 引擎：Godot 4.6.3，固定物理频率 60 Hz
>
> 实验场景：`res://curling/tests/throw_parameter_experiment.tscn`

## 1. 结论摘要

1. **不擦冰且未碰撞、未出界时，滑行时间只由力度决定。** 出手角度和旋转输入不会改变速度衰减，也不会改变自然停稳时间。
2. 力度 `P` 以 HUD 百分数表示时，实测自然滑行时间可写成：

   `t_stop = 9.03499 + 0.170649 × P` 秒，`0 ≤ P ≤ 100`。

   拟合 `R² = 0.9999991`，21 个档位中的最大误差为 `0.0086s`，小于一个 60 Hz 物理帧。
3. **每增加 1 个力度百分点，自然滑行时间约增加 `0.17065s`。** 比赛还会等待 `0.5s` 确认所有壶稳定，因此无碰撞时完整本手时间约为 `t_stop + 0.5s`。
4. 当前 UI 的“旋转”数值实际是**出手瞬间的角速度**，单位为 `rad/s`，不是固定旋转角。77% 力度下，`±1.2 rad/s` 最终约转 `±2.954` 圈并横移 `±1.520m`，但自然滑行时间仍与零旋转完全相同，都是 `22.167s`。
5. 出手角度和旋转会改变玩家看到的“有效滑行时间”，原因是它们可能让壶提前碰到侧边界。77% 力度直投自然滑行 `22.167s`；但 `+6°` 且 `+1.2 rad/s` 时，仅 `6.667s` 就会侧边出界。
6. 上一个任务中的 **77% 无擦冰推荐值成立**：直线零旋转时自然滑行 `22.167s`，加停稳确认后本手约 `22.667s`，停在 Tee 后方 `1.154m`，距营垒后方合法极限仍有约 `0.820m` 余量。78% 仅余约 `0.243m`，79% 已出营垒。

## 2. 参数和时间定义

### 2.1 力度

HUD 力度 `0%–100%` 被线性映射为初速度：

`v0 = 1.39319 + 0.0257647 × P` 米/秒。

冰面基础减速度为 `0.151m/s²`，停止阈值为 `0.03m/s`。不擦冰时，理论关系为：

`t_stop ≈ (v0 - 0.03) / 0.151`。

Godot 实测结果与该关系一致，差异主要来自 60 Hz 的停止判定量化。

### 2.2 出手角度

角度是初始速度方向相对赛道中线的夹角。本实验使用 `-6°、-3°、0°、+3°、+6°`。正负号只代表赛道两侧，不代表力度变化。

### 2.3 旋转

实验使用 `-1.2、-0.6、0、+0.6、+1.2 rad/s`。旋转会逐渐衰减，半衰期为 20 秒。物理实现只旋转速度方向，并保持速度大小不变，因此旋转影响弯曲和横向落点，不直接影响自然滑行时间。

### 2.4 两种时间

- **自然滑行时间**：从 `launch()` 到速度降至 `0.03m/s` 停止阈值。
- **有效滑行时间**：真实赛道中，从出手到自然停稳或提前出界，先发生者为准。
- **完整本手时间**：自然停稳后还需约 `0.5s` 稳定确认；提前出界时按比赛流程更早结束。

## 3. 实验设计

- 使用比赛场景中预分配的 16 颗 `CurlingStone` 刚体，没有使用公式模拟代替场景物理。
- 力度扫描：`0%–100%`，每 5% 一档，共 21 档，每档重复 4 次，共 84 次。
- 无边界全因子实验：4 档力度 × 5 个出手角 × 5 档旋转 × 4 次重复，共 400 次。
- 真实赛道边界实验：同样的 400 组组合，逐物理帧调用正式规则 `CurlingRules.is_out_of_play()`。
- 总投掷次数：`884` 次。
- 每个组合的 4 次重复会轮换到不同的比赛冰壶刚体。
- 全部实验均为零擦冰、无其他壶碰撞、Host 权威物理、固定 60 Hz。
- 为排除壶之间的碰撞干扰，实验时关闭了实验壶之间的碰撞层；赛道侧边和背线规则保持启用。

## 5. 对问题的直接回答

### 出手角度如何影响滑行时间？

- **自然滑行时间：不影响。** -6° 到 +6° 的实测时间完全相同。
- **真实场内有效时间：可能大幅缩短。** 角度越偏，越可能提前侧出。

### 旋转如何影响滑行时间？

- **自然滑行时间：不影响。** -1.2 到 +1.2 rad/s 的实测时间完全相同。
- **真实场内有效时间：通过横向弯曲间接影响。** 弯向边线会提前出界，弯回中线会延长留场时间。
- 旋转不要求额外力度来维持相同的自然滑行时长。

### 力度如何影响滑行时间？

- **直接且近似严格线性。** 每增加 1 个力度百分点，自然滑行约增加 `0.17065s`。
- 更大力度也会以近似二次关系增加总路径，所以高力度壶更容易越过背线，实际有效时间反而可能因出界而缩短。

### 三者一起作用时怎样理解？

先由力度决定“如果没有边界，能滑多久”；再由出手角度和旋转共同决定轨迹是否在这段时间结束前碰到边界。不能把提前出界误判为旋转增加了阻力。

## 6. 实验限制

- 本报告只研究无擦冰、无其他壶碰撞的 Host 权威物理。
- 与其他壶碰撞后，动量交换会改变速度和时间，不能套用本报告的单壶时间表。
- 擦冰会降低阻力并减少弯曲，需要使用单独的热量路径实验。
- 网络客户端显示由 Host 快照驱动；网络延迟可能影响动画观感，但不改变 Host 记录的物理结果。
- 时间分辨率为 `1/60s`。报告中的 `0.0000s` 极差表示所有样本在同一物理帧达到停止阈值。
