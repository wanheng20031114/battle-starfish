# Battle Starfish 冰壶玩家说明书

本文说明当前版本的实际操作与判定。游戏借用了冰壶规则，但以程序中的实现为准。

> **Hack 起点和赛道中线都没有障碍。** 中线也不会触发任何规则判定；附近没有可见冰壶却发生碰撞、减速或反弹属于异常，不是玩法规则。

## 1. 快速开始

1. 启动游戏，在主菜单选择“冰壶”。
2. 输入 2–16 个可显示字符作为用户名。
3. 选择对局长度：1、2 或 4 个 End（局）。
4. 选择一种多人连接方式：
   - **创建 LAN 房**：在本机开放局域网房间。
   - **加入 LAN**：输入 Host 的局域网 IP；留空时使用 `127.0.0.1`。
   - **创建公网房**：创建带 6 位房间码的测试房。
   - **加入代码房**：输入 6 位房间码加入。
   - **快速匹配**：自动寻找或创建公网测试房。
5. 进入房间后选择红队或蓝队并点击“准备”。Host 确认阵容后开始比赛。

合法阵容为 2–8 人，每队 1–4 人，两队人数差不能超过 1。无论队伍有几名玩家，每队在一个 End 中都投 8 颗壶。

## 2. 一局比赛怎样进行

每个 End 依次经过以下阶段：

1. **战术分配（120 秒）**：队员认领本队的 8 个投壶位并分别确认。
2. **交替投壶**：非后手队先投，两队轮流出手，共投 16 颗。
3. **擦冰与碰撞**：冰壶运动时，投壶方全队都可参与擦冰。
4. **计分**：所有壶停稳后，比较目标营垒内各壶到圆心的距离。

未被认领的投壶位会在锁定时自动分配：优先分给当前已分配次数最少的队员；次数相同时，先进入房间者优先。

开局随机决定后手队和投掷方向。当前版本每个 End 结束后，后手队与投掷方向都会交替。若预定 End 全部打完仍平分，比赛会追加 2 个 End；之后仍平分则继续成对追加，直到分出胜负。

## 3. 投壶操作

轮到自己时：

1. 在当前冰壶附近按住鼠标左键。
2. 向目标方向的反方向拖拽。拖得越远，力量越大；拖到窗口较短边约三分之一时达到满力。
3. 松开左键出手。画面中的轨迹线是无碰撞预测，只用于辅助瞄准。

旋转与取消：

- `Q` / `E`：连续减少 / 增加旋转。
- 鼠标滚轮：向下 / 向上逐格减少 / 增加旋转，每格调整 `0.08 rad/s`。
- 鼠标右键：取消当前拖拽。
- 瞄准限时为 60 秒；超时会记为空投并进入下一手。

观察赛道：

- `←` / `→` 或 `A` / `D`：沿画面左右方向连续移动视角。
- 冰壶开始滑行后进入擦冰阶段，镜头会自动跟踪本手冰壶；停稳后恢复手动观察。

旋转会让冰壶在减速过程中横向弯曲。轨迹预览不计算与其他冰壶的碰撞，因此撞壶后的真实路线可能与预览不同。

### 新手标准入垒投法

先在没有挡壶的直线路径上练习：

1. 让发射方向沿中线指向远端 Tee（营垒圆心）。
2. 把旋转保持在 `+0.00`，先练直投。
3. 向后拖拽，观察 HUD 力量条中的数字，到 `77%` 左右松手。
4. 第一遍先不擦冰，观察自然停点。
5. 后续每次只调整 `1%`：过短加 1%，过长减 1%。

当前物理标定下的参考值（除最后一行外均为不擦冰）：

| 投法目标 | 起手力量 | 擦冰建议 |
| --- | ---: | --- |
| 营垒前半 | 约 `72–74%` | 不擦或只在明显过短时轻擦 |
| Tee 附近 | 约 `75%` | 精确标定值，先不擦 |
| 新手推荐安全入垒 | 约 `77%` | 不擦；停在 Tee 后约 1.15 米 |
| 靠近营垒后沿 | 约 `78%` | 不擦；只剩约 0.24 米余量，79% 已出营垒 |
| 计划持续强擦 | `69–70%` | 全程擦冰可把停点延长约 3.2 米 |

场景实测中，77% 直线壶滑行约 22.17 秒，加上 0.5 秒停稳确认后本手约 22.67 秒；它比 78% 多保留约 0.58 米后沿余量，因此更适合作为默认推荐。在 75–77% 附近，每改变 1 个百分点，最终停点大约变化 0.6 米。先按 1% 微调，连续过短就加 1%，连续过长就减 1%。

擦冰只能让壶滑得更远并减少弯曲，不能让过重的壶减速。因此：

- 看起来会停在营垒前方时，再按住左键快速擦冰。
- 预计已经能停进营垒时应停止擦冰。
- 以 77% 出手后不应持续满擦，否则会明显过长；计划全程擦冰应从 69–70% 起手。

熟悉直投后再练旋转。旋转不改变停止时间和总滑行路径，只改变横向弯曲；曲线路径沿原瞄准方向的前进投影会略短，但这不是额外阻力。实测 75% 最大旋转仍滑行 21.83 秒、总路径仍为 36.59 米，纵向投影只少约 6.3 厘米，相当于约 0.11 个力度百分点，通常无需专门补力。最大旋转在完整行程中约产生 1.5 米横移，几乎等于营垒半径。观察轨迹线弯向哪一侧，再向反方向预留瞄准量。满擦会让弯曲量减少约 35%，所以旋转投法中途大量擦冰也会改变横向落点。

## 4. 擦冰操作

冰壶出手后，投壶方所有在线队员都可以：

1. 按住鼠标左键；
2. 在冰壶前方快速来回移动鼠标。

有效擦冰会短暂加热经过的冰面，使冰壶滑得稍远，并减弱弯曲。多人擦冰贡献可以叠加，但热量有上限且会快速衰减。鼠标只按住不移动，或移动过慢，不会产生明显效果。

本手滑行壶上方会持续显示“预计剩余 X.X 秒”。冰面受热后还会显示“擦冰 +X.X 秒”，让玩家直接看到当前擦冰预计延长了多少滑行时间。该数值根据当前速度与热量实时估算；发生碰撞、停止擦冰或热量衰减时都会继续更新。

## 5. 赛道标线与出界

以下示意以向右投掷为例；反向 End 会左右镜像：

```text
出手端                                                                 目标端
Hack（起点） ─────── 中线 ─────── 远端 Hog Line ─── 自由防守区 ─── Tee（圆心） ─ Back Line
                    仅视觉参考          最低有效距离         营垒外前场          营垒          背线
```

- **Hack（起点）**：只用于放置本手冰壶，没有碰撞体。
- **中线**：只用于视觉定位，没有碰撞，也没有越线惩罚。
- **远端 Hog Line（红色粗线）**：本手冰壶停稳时必须整颗越过这条线；若没有越过且途中也没碰到其他壶，本手冰壶会被移出场外。
- **边线**：冰壶触及赛道侧边界即出界。
- **Back Line（背线）**：冰壶整颗越过目标端背线后出界。
- **House（营垒）**：目标端同心圆区域。壶只要接触营垒外圈，就有资格参与计分。
- **Tee（圆心）**：同心圆中心，也是计分距离的测量点。

## 6. 五壶保护区规则

自由防守区位于远端 Hog Line 与 Tee 之间、但不包含营垒。

在一个 End 的前 5 手中，不能把对方原本位于自由防守区的壶击出场。若对方保护壶压在中线，也不能把它 tick 到离开中线或离开保护区。若发生这种情况，程序会把整条冰道恢复到本手出手前的状态。本手仍计入已经投出的壶数。

## 7. 计分

一个 End 的 16 颗壶全部处理完后：

1. 只统计仍在营垒内或接触营垒外圈的壶。
2. 离 Tee 最近的一方是该 End 唯一得分方。
3. 该队每有一颗壶比对方最近的壶更靠近 Tee，就得 1 分。
4. 若双方最近距离判定为相同，或营垒内没有有效壶，本 End 为 0 分。

示例：红队最近两颗壶都比蓝队最近一颗更靠近 Tee，则红队得 2 分，蓝队得 0 分。

## 8. 房间、聊天与断线

- 房间开始前，玩家可自行换队；Host 也可为玩家调队。被调队后需要重新准备。
- 比赛内聊天可选择“队伍”或“全局”频道，在输入框中按 `Enter` 发送。
- 公网模式会在本机保存临时恢复信息。短暂断线后，返回大厅可使用“恢复”按钮；恢复窗口约为 90 秒。
- 当前版本没有 Host 迁移。Host 离线会导致公网房间结束。
- 公网测试使用明文 HTTP 与普通 ENet，不适合传输敏感信息，也不提供竞技级反作弊。

## 9. 设置与快捷键

- `Esc`：关闭当前弹层；没有弹层时打开设置。设置界面不会暂停比赛计时、物理或网络同步。
- `F1`：在比赛中打开或关闭可滚动说明书。说明书打开时只锁定本地投壶与擦冰，比赛仍继续运行。
- `F3`：显示或隐藏只读网络 / 物理诊断信息。
- 设置项包括窗口模式、分辨率、主音量、音效音量和“降低镜头运动”。
- 设置与用户名会自动保存到本机 `user://curling_settings.cfg`。

## 10. 常见问题

### 为什么冰壶在起点或赛道中间突然反弹？

这不是规则。Hack 起点与中场都应完全可通行；附近没有可见冰壶却发生碰撞属于 Bug，请记录画面与当时操作。

### 为什么壶停下后突然消失？

常见合法原因有三种：触及边线、整颗越过目标背线，或本手停稳后未整颗越过远端 Hog Line 且没有碰到其他壶。界面底部会显示最近一次规则提示。

### 为什么击球后所有壶恢复原位？

这是五壶保护区违规：前 5 手中把对方自由防守区的保护壶击出了场，程序会恢复本手之前的场面。

### 为什么我不能出手？

只有当前投手能在瞄准阶段出手。请确认设置面板已关闭，并从当前壶附近开始拖拽。投掷方向与拖拽方向相反。

### 为什么擦冰没有效果？

只有当前投壶方能擦冰；需要按住左键并快速移动鼠标。热量会很快衰减，且多人贡献达到上限后不会继续增强。

## 11. 开发版启动方式

- 使用 Godot 4.6 打开项目，运行 `res://curling/curling.tscn`。
- Windows 可在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File curling/tools/run_curling.ps1
```

LAN Host 使用 UDP `40150`，局域网发现使用 UDP `40151`。若防火墙拦截，请只在受信任的局域网中放行对应端口。
